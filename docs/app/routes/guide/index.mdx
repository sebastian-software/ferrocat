# Guide

Start here when you want to understand Ferrocat as a product, not just as a crate list. The guide starts from the practical workflow: keep translations reviewable, validate them before release, and compile runtime payloads your application can load predictably. The technical formats matter, but they are introduced as tools for that job.

## In this section

- [Getting Started](/guide/getting-started) for installation, a first parse/stringify example, and the main product workflows
- [Catalog Modes](/guide/catalog-modes) for how Ferrocat uses PO, ICU, and NDJSON without making them the whole product story
- [Runtime Compilation](/guide/runtime-compilation) for turning catalogs into application-ready artifacts
- [Ferrocat And Palamedes](/guide/palamedes) for how the catalog engine connects to the JS/TS i18n framework
- [Project Status](/guide/project-status) for current strengths, roadmap themes, and compatibility policy
- [Releases And Upgrading](/guide/upgrading) for changelog locations, lockstep versions, and safe pre-`1.0` upgrades
- [Community](/guide/community) for contributing and operational links
